거창한 기능이 아니라, 내가 실제로 겪던 작은 마찰에서 출발했습니다.

1

어디까지 했더라?

퇴근했다 다음날 출근하면, 어떤 프로젝트를 어디까지 했는지 늘 까먹었습니다.

“결국 노트에 적어두고 퇴근하는 게 일상이었다.”
2

이 세션 목표가 뭐였지?

여러 세션을 동시에 돌리다 보니, 지금 무엇을 왜 돌리는지 점점 흐려졌습니다.

“창은 여러 개인데, 각자의 목표가 머릿속에서 뒤섞였다.”
3

git 보려고 또 딴 앱?

현재 브랜치·변경사항을 확인하려고 GitHub Desktop이나 VS Code를 따로 켜야 했습니다.

“회상하던 흐름이 끊기고 창만 늘어났다.”

🔒

로컬 전용

외부로 노출되지 않습니다. 서버·포트 없이, git 작업도 내 컴퓨터의 CLI를 그대로 호출합니다.

🎯

내 환경만

모든 파일 작업은 허용된 경로(~/.claude) 안에서만. 벗어나면 거부합니다.

📦

삭제 없음

정리는 ‘삭제’가 아니라 archive 폴더로 ‘이동’입니다. 언제든 원위치로 복구할 수 있습니다.
